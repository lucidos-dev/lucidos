0 · Current cards baseline

Today's look: every turn is a bordered, two-tone panel (header bar on bg-secondary, body on bg-primary) with a role-colored left edge; engine panels add a tinted header and a reason-colored summary line. Heavy: a box per turn, lots of borders.

1 · Transcript most minimal

No boxes — a plain (gray, uncolored) speaker name over flush text; your own messages and change events drop the name entirely. Click any name, timestamp, or dot for the initiator popover (who · device / model). Pros: calm and dense, reads like a log. Watch: with names decolored, role leans on the icon + reason-colored summary.

2 · Left-rail timeline structured

A continuous gutter line threads the conversation; a variant-colored dot marks each turn (engine = teal, you = blue, agent = amber). Pros: strong through-line, fits the terminal aesthetic. Watch: the gutter costs ~1.8rem of width.

3 · Minimal accent bar smallest change

Keep only the variant-colored left rule from today's cards; drop the surrounding border and the header background bar. Pros: closest to current, preserves at-a-glance role + reason color. Watch: still a vertical rule per turn.

4 · Asymmetric bubbles most familiar

User messages right in a subtle pill; agent left as plain text; every engine/trigger/change event becomes a centered system note. Pros: instantly familiar. Watch: the user pill + system notes are still boxes, so this is the most card-adjacent.

5 · Hybrid mixed

User messages as a right-aligned bubble; everything else (agent output, trigger, engine, change, child thread, question) as flush transcript. Pros: your own input pops, everything the system shows you stays uniform and card-less. Watch: only the bubble breaks the flat rhythm.
