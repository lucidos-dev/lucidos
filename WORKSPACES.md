# Workspaces

This file holds machine- and team-specific workspace conventions used during
internal development of Lucidos — which workspace directories are run, which hold
live data, and any local browser/testing setup. That content is intentionally
omitted from the public release.

If you are working in this repository, use this file for your own local notes,
and see [`CLAUDE.md`](CLAUDE.md) § Working in a Workspace for the general rules it
makes concrete (reads are always fine; mutations need ownership + confirmation).
