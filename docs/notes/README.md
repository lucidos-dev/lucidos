# Notes

Architecture discussions written down so they are not lost in a chat thread.

**A note is not a plan.** Nothing here is scheduled, decided, or implemented.
A note records the shape of a problem, the options considered, and the open
questions, at the moment someone thought about it.

Where things go:

- `docs/notes/` (here): thinking. No commitment. May sit untouched for months,
  may be abandoned, may be wrong later.
- `docs/adr/`: a decision, once one is actually made, with the reasoning and
  the rejected alternatives.
- `docs/plans/`: the implementation plan for work that is going to happen.
  Written via the `implementation-plan` skill, gated by `lucidos planned`.

A note graduating to real work means writing an ADR for the decision and a plan
for the build. The note stays as the record of how the thinking got there.
